# dene_train

東急田園都市線を題材にしたすごろくWebアプリです。

- 渋谷スタート
- 渋谷 ⇄ 中央林間を自動往復
- 出目 → 車種 → 種別を自動抽選
- 各抽選は2秒アニメーション＋3秒結果表示
- 停止駅に★表示
- 各駅停車／準急／急行の停車駅表示
- セーブ／ロード、JSON書き出し・読込、ミッション機能

## 公開

`index.html` をそのまま GitHub Pages で公開できます。

Repository Settings → Pages → Build and deployment → Source を `Deploy from a branch` にして、Branch を `main` / `(root)` に設定してください。
